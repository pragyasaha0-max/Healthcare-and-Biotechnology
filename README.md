# Healthcare and Biotechnology: portfolio template

Open `index.html` for a clean biotech-style portfolio template with placeholder content (hero, profile strip, project cards, counting stats bar, experience, skills with animated map, contact banner). The sample text is the `SAMPLE` list at the top of the script in `page.html`; edit it and run `python3 build.py`.

- `index.html` – the page (theme, script and images inlined so it works on its own)
- `clinical-light.css` / `clinical-light.js` – the reusable theme (all classes prefixed `hc-`)
- `page.html`, `helpers.js`, `build.py` – source: page template, text parser, build script (`python3 build.py`)
- `img/` – photos cut from the Nexora design; `prep.py` is how they were cut

Theme features: scroll reveal, word-by-word headings, counting numbers, light that travels round box borders, hover spotlight, pulsing map pins. Colours live in the first block of `clinical-light.css`.
